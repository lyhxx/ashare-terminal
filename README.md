# A股情绪轮动终端

> 一个本地运行的 A 股**市场情绪与资金流向**实时监控终端。服务端实时代理多家公开行情接口，前端动态渲染，打开页面即拉取当日真实数据，无任何内嵌静态数据。

仓库名：`ashare-terminal`

## 功能

- **情绪日报**（`/`）：全市场龙虎榜（代码/名称/涨跌幅/净买入/上榜原因/换手率）、同花顺当日强势股题材热点词频、行业涨跌榜与净买入排名。
- **行业轮动仪表盘**（`/dashboard`）：大盘概览、今日资金主线、行业涨跌热力网格（涨红跌绿·深浅表强度）、主力资金行业净流入排行（双向条形）、风格轮动强弱（大盘/中盘/小盘 × 价值/成长）、北向资金动向、3 条行业配置研判。
- **交互**：交易日选择、「今日(实时)」按钮、手动刷新、自动刷新（30s / 1m / 2m / 5m，当日数据最小间隔 30s）。
- **视觉**：暗色金融终端风，A 股惯例涨红跌绿，金额单位 ¥（亿/万）。

## 运行

```bash
pip install -r requirements.txt
python app.py          # 默认 http://localhost:8000
```

- Windows 用户可直接双击 `run_server.bat`（自动调用隔离 venv，规避中文路径编码问题）。
- 端口可用环境变量覆盖：`PORT=9000 python app.py`。

## 数据来源

- **东方财富**：龙虎榜（`RPT_DAILYBILLBOARD_DETAILSNEW`）、行业板块涨跌排名、实时行情（主要指数 / 国证风格指数 / 沪深港通北向）。
- **同花顺**：当日强势股题材归因（`zx.10jqka`）。

> 北向盘中实时净买入自 2024-08-19 起已停披露，相关数值为最近可得口径并在页面明确标注，不绘制假的 20 日趋势线。

## 项目结构

```
app.py            Flask 动态服务（/api/snapshot、/api/rotation、/、/dashboard）
fetch_data.py     情绪日报数据抓取（龙虎榜 / 同花顺题材 / 行业板块）
rotation_data.py  轮动仪表盘数据整合（指数 / 风格 / 行业 / 北向 / 研判）
static/style.css  统一设计系统（暗色金融终端风）
static/app.js     共享前端助手（格式化 / 双向条形图 / 自动刷新）
index.html        情绪日报页
dashboard.html    行业轮动仪表盘页
run_server.bat    Windows 一键启动（隔离 venv）
```
